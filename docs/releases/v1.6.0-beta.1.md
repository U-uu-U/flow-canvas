# Flow Canvas v1.6.0-beta.1

## 本版更新

- 汇总 1.6 前代码审核修复，完善生成任务、项目切换和节点结果状态同步；中断、失败和历史结果恢复不会误写到其他项目或覆盖新任务。
- 修复复制节点后删除副本影响原视频的问题，清理节点引用与删除源文件分开处理。
- 生成图片和视频使用本地规则提取提示词命名，保留递增编号，无需额外 API 调用。
- 剪切素材支持所有文件夹组中的目标文件夹，同步更新素材路径、节点及连线，抑制文件移动产生的重复删除通知。
- 框选支持方向区分：从右向左碰到即选中，从左向右完整包围才选中。
- 加入 HM-Seedance 新规格和人民币售价说明，保留固定 30 秒的两条线路与独立的可调时长模型。
- 线路选择从模型卡片右侧展开，窗口边缘自动避让；模型列表隐藏滚动条，保留滚轮和触控板滚动。
- 设置中增加 UI 跟随缩放上限，统一控制连线、节点加号、视频播放/静音及进度条；小尺寸视频继续隐藏播放控件。
- 统一左侧工具栏、底部视图栏、Agent 顶部按钮与视频占位图标，优化深浅主题、主题色和启动界面。悬浮球只保留经典外观。
- 统一顶部错误提示，支持复制和关闭；清理旧生成侧栏残留通道，继续通过画布节点和 Agent 创作。

## 下载

- `Flow.Canvas.Setup.1.6.0-beta.1.exe`：Windows x64 安装版。
- `Flow.Canvas.1.6.0-beta.1.exe`：Windows x64 便携版。
- `Flow.Canvas.1.6.0-beta.1.mac.universal.dmg`：macOS 通用安装包，支持 Apple Silicon 和 Intel。

两个平台使用同一份 `master` 源码提交。升级时退出旧应用后安装新版，沿用已有项目、素材和 API 配置。

## 验证

- 本地通过 Lint、921 项测试和前端构建，并验证线路菜单、视频播放/静音、缩放及主要界面控件。
- Windows 和 macOS 分别运行测试并打包；macOS 另验收打包后的 Agent 运行时、视频解码和界面。
- 本版不新增付费模型探针，不将已知可用请求扩大表述为第三方渠道全部参数均已验证。
- 本版为预发布，不替换现有稳定版；macOS 包未使用 Apple Developer 身份签名和公证。
