# Flow Canvas v1.5.0-beta.10

## 本版更新

- 包含 beta.9 的全部功能修复，并修正 Windows 构建测试中长路径与 8.3 短路径别名被误判为不同文件的问题，重新提供同源的双平台安装包。
- 修复复用生成节点时引用说明反复追加的问题，保留原始提示词、胶囊引用和素材顺序，避免多次生成后提示词越来越长。
- 明确区分 Seedance 2.5 固定 30 秒线路一、线路二，恢复独立的 `seedance_v2.5` 可调时长模型（4-30 秒）。
- 接入模型能力 CONFIG 配置及更新服务。只拦截已确认不支持或越界的参数；未核实参数保留为提示，不推测性禁用。
- 移除未接入的 Seedance 1.5、Wan、Kling、Vidu 内置模板，保留用户自定义 API、历史节点和任务数据。
- 改善大图、WebP、TIFF 等素材预览的兼容解码和错误提示，保持原始尺寸及画布比例；临时读取失败、文件尚未写完时自动重试。
- 素材预览增加有界缓存、并发限制和重复请求合并，避免资源节省模式切换后的旧回调干扰当前画布。
- 删除旧侧栏的图片、视频生成工作区及专用提交、缓存读写和样式。继续使用画布生成节点，保留 Agent、API 设置、任务 ID 恢复和提示词预设。

## 下载

- `Flow.Canvas.Setup.1.5.0-beta.10.exe`：Windows x64 安装版。
- `Flow.Canvas.1.5.0-beta.10.exe`：Windows x64 便携版。
- `Flow.Canvas.1.5.0-beta.10.mac.universal.dmg`：macOS 通用安装包，支持 Apple Silicon 和 Intel。

Windows 和 macOS 使用同一源码提交。升级时退出旧应用后安装新版，现有 API 和项目数据继续沿用。

## 验证与说明

- 源码测试集包含 714 项测试；模型 CONFIG 刷新/回滚、素材预览及重启恢复烟测已通过。
- Windows 和 macOS 构建各自运行测试；macOS 额外检查打包后的 Agent 运行时、视频解码和主要界面控件。
- MJ 仅确认已测试的一组初始四图请求成功，不代表全部官方参数在第三方渠道中均可用。本次打包不再发起付费生成探针。
- 本版为测试版，不替换现有稳定版。macOS 包尚未使用 Apple Developer 身份签名和公证。
