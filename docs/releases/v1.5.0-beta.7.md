# Flow Canvas v1.5.0-beta.7

## 更新内容

本版集中修复一组「静默失败 / 永久卡死 / 非预期计费」类缺陷。全部改动均伴随回归测试。

### 严重

- **修复取消参考图处理时生成静默丢弃全部参考素材。** 参考图合计超过 6 MB 时会弹出处理提示，此时按 `Esc` 或「取消」会丢弃全部参考图、改以纯文生图提交，而提示词里的「图一/图二」编号说明仍然保留——模型收到的是一段引用着不存在图片的文字。现在会**明确中止生成并给出可操作提示**，不再静默降级。
- **修复节点级运行锁泄漏导致整条节点链永久不可运行。** `GraphRunner` 的状态回调（画布重绘）一旦抛错，异常会在加锁与 `try` 之间逃逸，`finally` 不执行，`activeNodes` 永久残留——该节点链在本会话内再也跑不起来，只能重启。现由 `_setStatus` 隔离回调异常。
- **修复规划表「生成结果图」永久失效。** 仅配置视频 API 时，代码在 `try` 之外解引用图片 Provider，抛错后 `_isGeneratingPlanRow` 永久为真，此后每次点击都静默返回、无任何提示。

### 高

- **修复拖动带结果的视频生成节点时崩溃。** 该节点没有 `filePath` 属性，但其结果预览带有 `videoControls` 标记，磁吸吸附改尺寸时对 `undefined` 调用 `.match` 抛 `TypeError`，导致拖拽期间连线与端口不跟随。
- **修复生成失败后仍继续消耗额度。** 并发批处理在首个任务失败后，其余 worker 会继续领取剩余任务：图片会下载孤儿产物并把任务记录写成成功（节点却是失败），视频会继续提交付费任务。现在失败后立即停止派发。
- **修复「生成」按钮永久禁用。** 参考图处理弹层被新的弹层顶替时，旧弹层的 Promise 永不结束，调用方的 `finally` 不执行，按钮永久 `disabled` 且无提示。现在顶替前会正常收尾。
- **修复取消按钮在残留「生成中」节点上无反应。** 进程被杀或渲染层重载后，节点会持久化停在运行中状态，而取消操作对此类运行返回失败且不给任何反馈。现在会就地复位节点状态并提示。
- **修复一次 `Ctrl+Enter` 触发两条运行路径。** 画布会同时走面板提交与全局「运行节点」快捷键，可能产生一次非预期的付费生成；面板侧现在会阻止事件继续冒泡。
- **修复撤销/重做时生成面板输入丢失。** 面板在画布清空后仍然存活并指向已游离的数据对象，继续输入不会写回当前状态。现在会在清空时关闭面板。

### 中

- **修复视频任务恢复会用过期快照覆盖画板。** 恢复流程最长可轮询约一小时，期间画板上的任何并发修改（用户、MCP、Agent）都会被静默回滚。现在与图片路径一致，在写入前重新读取画板。
- **修复「结果未知」被当作「确定失败」。** 上传/生成请求中断时，诊断信息本身写着「无法确认服务端是否已受理…不要连续重复生成」，界面却因关键词匹配给出「重新提交会创建新任务」的建议，可能导致重复计费。现在由结构化标记判定并显式跨进程传递。
- **修复视频提交连接失败后任务永久不可重试。** `fetch failed` 属于连接阶段的失败，被误判为「服务端可能已受理」并用本地日志 ID 充当远端任务 ID，导致任务既无法重试、拉取又必然失败。
- **修复快捷键录制状态在面板关闭后不解除。** 该状态下全应用按键被拦截，输入框无法输入，且第一个按键会被静默写成新绑定。
- **修复取消生成时真实错误被吞掉。** 错误分类原先依赖中文关键词匹配，任何含「已取消 / cancel」字样的真实失败都会被当作用户中断，节点被标记为已中断、真实失败原因丢失、重试入口消失。现在只认应用自己写入的结构化标记。
- **修复启动失败提示不显示。** 模块作用域的日志调用引用了函数内部的局部函数，启动失败时会先抛 `ReferenceError`，导致「启动失败」诊断对话框永远不弹出——而这正是排查无法启动问题的入口。
- 统一参考图可引用性判定，修复参考缩略图显示编号与点击后插入的引用编号不一致的问题。

## 验证方式

```powershell
npm test        # 595 个用例
npm run build
```

手动回归要点：

1. 引用合计超过 6 MB 的参考图并生成，在处理提示中按 `Esc` → 预期**明确中止并提示**，且不产生任何生图请求；
2. 在只有视频 API 的配置下点击规划行「生成结果图」→ 预期给出明确提示，且**后续点击仍然有效**（不再永久失效）；
3. 拖动一个已出结果的视频生成节点，与不同高度的节点吸附 → 预期不再报错，连线正常跟随；
4. 用数量 > 1 触发并发生成，令其中一个失败 → 预期不再有后续请求被发出；
5. 打开生成面板后按 `Ctrl+Z` 撤销 → 预期面板关闭，不再有输入丢失。
