# Flow Canvas v1.5.0-beta.8

## 本版更新

- 视频模型选择改为 Seedance 2.5 卡片，悬停展开线路一和线路二，保留当前线路提示，支持键盘操作。
- RavenHash 新增独立线路一，原固定 30 秒线路保留为线路二；历史节点和任务继续绑定原线路。
- 修正线路一的提交字段、任务查询路径和任务 ID 识别；服务端按 30 秒间隔轮询，并处理需要上游鉴权的视频下载。
- 线路一、线路二沿用每次 6 元人民币的售价，不将上游美元成本当作人民币售价。
- 保留 beta.7 的参考素材、任务取消、重复提交防护、资源节省模式视频封面和小尺寸播放控件修复。
- 合入协作者新增的 lint / 测试检查；Windows 构建现在明确构建最新界面并保存安装包产物。

## 下载

- `Flow.Canvas.Setup.1.5.0-beta.8.exe`：Windows x64 安装版。
- `Flow.Canvas.1.5.0-beta.8.exe`：Windows x64 便携版。
- `Flow.Canvas.1.5.0-beta.8.mac.universal.dmg`：macOS 通用安装包，支持 Apple Silicon 和 Intel。

两个平台使用同一源码提交。升级前退出旧应用，再打开新版，以加载主进程中的新模型适配；现有 API 和项目数据继续沿用。

## 说明

这是测试版，不覆盖已有稳定版本。macOS 包未进行 Apple 开发者签名和公证。
线路一服务端修复已部署；上游返回任务不存在的旧任务不会被自动重发，需由上游核查。未在本次打包过程中发起付费生成。
