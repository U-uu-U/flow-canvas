# Flow Canvas v1.5.0-beta.5

## 更新内容

- 修复参考图缺失或格式不支持时被静默忽略的问题；素材不完整时停止生成并提示处理。
- 修复引用胶囊在节点连线变化、重新打开和复用生成结果时丢失或错位的问题。
- 修复上游多图素材列表漏传，保留参考图上传顺序。
- 增强生成产物解析与任务恢复，改善中断后的结果获取。
- 完善视频任务审核失败和恢复状态提示；有可恢复任务 ID 时优先继续查询原任务。
- 增加实际上传参考图的数量、顺序与文件指纹诊断信息，便于排查素材问题。

## 下载

- Windows 安装版：`Flow.Canvas.Setup.1.5.0-beta.5.exe`
- Windows 便携版：`Flow.Canvas.1.5.0-beta.5.exe`
- macOS 通用版（Apple Silicon / Intel）：`Flow.Canvas.1.5.0-beta.5.mac.universal.dmg`

此版本为测试版。安装包尚未代码签名，macOS 包未经过 Apple 公证。
