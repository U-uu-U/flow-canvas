# Flow Canvas v1.5.0-beta.6

## 更新内容

- 修复 macOS 启动与窗口激活的时序问题，等待服务初始化完成后再创建或恢复主窗口。
- 避免首次启动和激活事件并发时重复创建主窗口。
- 增加启动失败提示与日志，便于定位无法打开应用的问题。
- 包含 beta.5 的参考图上传、引用胶囊和生成产物恢复修复。

## 下载

- Windows 安装版：`Flow.Canvas.Setup.1.5.0-beta.6.exe`
- Windows 便携版：`Flow.Canvas.1.5.0-beta.6.exe`
- macOS 通用版（Apple Silicon / Intel）：`Flow.Canvas.1.5.0-beta.6.mac.universal.dmg`

此版本为测试版。安装包尚未代码签名，macOS 包未经过 Apple 公证。
