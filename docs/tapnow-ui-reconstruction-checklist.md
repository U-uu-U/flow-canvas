## 逐项顺序

1. `A01-A05`：先让整体画布层级接近参考。
2. `C01-C07`、`D01-D06`：统一节点外观和状态。
3. `F01-F07`：复原端口与连线体验。
4. `E01-E10`：把生成配置真正放入节点。
5. `G01-G05`：补齐弹层与快捷交互。
6. `H01-H09`：完成真实执行、持久化和性能闭环。
7. `B01-B12`：最后收口全局工具，避免早期 UI 反复改动。

每完成一组，需要固定视口截图、与参考页面并排检查，并将状态从 `待做` 更新为 `待核验`；完成第二轮修正后才能标记为 `通过`。
